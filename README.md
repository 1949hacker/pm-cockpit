# PM Cockpit · 个人项目管理驾驶舱

> 一个**零依赖的单文件 HTML** 项目管理看板模板。打开即用：看板卡片可拖拽排序、内置当月日历（工作日 / 休息日 / 节假日三态可自定义）、浏览器内直接编辑保存，不依赖任何后端或构建工具。

---

## 一、设计理念

**1. 单文件即工具**
整个项目管理视图就是一个 `.html` 文件，双击即用——无需安装、无需联网、无需服务器。适合个人项目管理、出海属地交付、跨时区协作等场景，文件可随 U 盘 / 网盘带走，也能直接发到即时通讯工具里预览（如钉钉）。

**2. 金字塔汇报结构**
看板按读者分层，同一份材料不同角色看到不同粒度，减少重复汇报：
- **L0 最高领导**：只看速览数字与结论；
- **L1 直接领导 + 协同方**：看拍板事项、协同方、动作清单；
- **L2 执行人（你自己）**：看进展看板、风险台账、关键时间节点。

**3. 驾驶舱隐喻**
把项目当作一架飞机来"开"。顶部速览让管理者一眼看到「已办结 / 进行中 / 受阻 / 待决策」的数量；当月日历标出关键节点；进展看板是实时仪表盘。点 L0 统计卡可平滑跳转到进展看板。

**4. 可编辑但克制**
内置浏览器编辑器：**编辑态**才能改页面，**浏览态**完全只读（仅展开 / 收起可交互），避免误改。保存通过 File System Access API 原地写回，不依赖云端。

**5. 零依赖、可携带**
纯 HTML + CSS + 原生 JS，没有任何第三方库。无构建步骤，改完即所得。

## 二、使用方法

### 1. 打开
直接用浏览器打开 `index.html`（推荐 Chrome / Edge）。无需任何安装。

### 2. 编辑
- 右上角工具条：点「菜单」→「编辑」进入编辑态；点「收起」变回「菜单」方块，再点「菜单」展开。
- 工具条按钮：`编辑 · 加卡 · 撤销 · 恢复 ｜ 保存 · 打印`。
- **卡片**：点标题行的蓝色「展开 / 收起」胶囊查看或收起 9 字段详情（执行人 · 来源 · 说明 · 需求 · 卡点 · 影响 · 依据 · 完成标准 · 节点）；拖住卡片左上角「⋮⋮」可在四列状态间拖动或调整顺序。
- **当月日历**：点标题唤起月份选择；编辑态点某天可切换「工作日 / 休息日 / 节假日」。
- 顶部蓝色按钮「全部展开 / 全部折叠」一键控制所有卡片。

### 3. 保存
编辑态点「保存」→ 浏览器请求选择要写回的文件（首次需选一次 `index.html`），之后原地保存。浏览态下页面只读。

### 4. 打印 / 导出
- 「打印」调用系统打印，可另存为 PDF（已自动隐藏工具条与编辑手柄）。
- 编辑态可导出整页超清 PNG（按当前展开 / 收起状态），适合贴进周报。

### 5. 移动端
页面响应式，手机浏览器可阅读；编辑与拖拽建议在桌面端操作。
